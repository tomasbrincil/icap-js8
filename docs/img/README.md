# Photos

Two photographs of the released build on the author's IC-705, taken by Tomas Brincil OK1BT on 23 November 2026 while receiving on 7.078 MHz (40 m), at 14:37 local time (UTC+1). They are part of the documentation and are covered by `LICENSE` / `NOTICE.md` like the rest of it. The captions, with every field of the app window explained, are in the README under "Photos".

| File | Shows |
|---|---|
| `js8-decode.jpg` | the DECODE screen with live JS8 traffic: four rows in the 40-column format, stations heard on 40 m, the mini-scope beside them |
| `js8-app-window.jpg` | the app window: the settings in use, the last period, decode times per stage, counters since the start |

The call signs that can be read in the first photo are those of stations heard on the air in public transmissions; nothing else about them is known or stated here.

## Rules for a photo in this folder

- JPEG only, named `docs/img/<lower-case-name>.jpg`, at most 400 kB.
- **No metadata.** The file must hold the picture and nothing else: a plain JFIF header, no Exif (camera, time, position), no XMP, ICC or IPTC block, no comment segment, nothing after the end of the image. The export check walks the segments of every photo byte by byte and refuses the file otherwise; both files above passed it.
- Before adding a photo, look at it for anything that should not be public: position, serial numbers, a screen of another device, other people's call signs in a context they did not choose.
